Why SendGrid HTTPS?
-------------------
SendGrid HTTPS uses standard REST API calls over Port 443 (HTTPS), completely
bypassing cloud provider SMTP port blocks (such as DigitalOcean blocking ports
25, 465, and 587). Every request is strictly encrypted via TLS 1.2/1.3 and uses
scoped, revokable API keys.

SendGrid provides a 100% Free Plan (100 emails/day forever) with no credit
card required.

Follow these 5 simple steps to get email sending live:

5. Check your inbox at bberry@calmchessgames.com and click the "Verify" button.
   (Once clicked, SendGrid immediately allows sending from this address).

--------------------------------------------------------------------------------
STEP 3: GENERATE YOUR API KEY
--------------------------------------------------------------------------------
1. In the SendGrid dashboard left sidebar, go to:

2. Click the blue "Create API Key" button (top right).

3. Set up the key:

--------------------------------------------------------------------------------
STEP 4: CONFIGURE THE API KEY ON YOUR SERVER
--------------------------------------------------------------------------------
You can activate the API key in either of two ways:

Method A (Direct in config.php - Recommended):
  1. Open config.php on your server (/var/www/html/config.php) or in your

  2. Locate the SENDGRID_API_KEY definition near line 24:
     define('SENDGRID_API_KEY', 'SG.your_actual_key_here');
  3. Save the file.

Method B (Via Environment Variable):
  Add to your server environment or Apache configuration:
